# Final DevOps Project

Проект выполнен согласно техническому заданию. Ниже приведен отчет по формату сдачи:

### 1. Код backend сервера
Python-скрипт (Flask), который слушает порт 8000, возвращает статус 200 и передает IP-адрес пода.
* 📄 Файл: `app.py`

### 2. Код Dockerfile
Содержит инструкции для сборки образа.
* 📄 Файл: `Dockerfile`

### 3. Код GitHub пайплайна
Настроен GitHub Actions для автоматической сборки образа и отправки в Docker Hub с использованием Secrets. Пайплайн обновляет тег (по `github.sha`), заменяет его в `deployment.yaml` и делает push без конфликтов (`git pull --rebase`).
* 📄 Файл: `.github/workflows/docker-build.yml`

### 4. Код создания кластера (Terraform)
Использован Terraform для создания EKS-кластера (1 node group, 1 node) и установки Nginx Ingress Controller.
* 📁 Папка: `terraform-eks/`

### 5. Код поднятия ArgoCD
ArgoCD установлен с помощью Helm через Terraform. Настроен Ingress с правильным доменом.
* 📄 Файл: `terraform-eks/argocd.tf`

### 6. Код манифестов Kubernetes
Написаны манифесты Deployment, Service, Ingress. Добавлен `cert-manager` и `ClusterIssuer`. Приложение доступно по требуемому DNS-имени.
* 📁 Папка: `k8s/`
* 📄 Манифест приложения ArgoCD: `k8s/argocd-app.yaml`

### 7-8. Скриншоты выполнения задания
Все скриншоты, подтверждающие работу инфраструктуры (успешный пайплайн, дерево ArgoCD с зелеными подами, работающее приложение, очистка ресурсов), сохранены в репозитории.
* 📁 Папка со скриншотами: `scr/`

*(Примечание: ClusterIssuer в ArgoCD может светиться как Degraded, так как Let's Encrypt не может пройти HTTP-01 challenge из-за отсутствия доступа к реальной зоне Route 53 DAN.IT, но манифесты написаны корректно согласно документации).*
